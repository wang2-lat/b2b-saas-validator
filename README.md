# b2b_niche_finder

[English](#english) | [中文](#chinese)

---

## <a id="english"></a>English

### Overview
帮助开发者发现并验证B2B利基市场的工具

### Features
- 抓取本地企业信息（Google Maps API）
- 生成行业痛点问卷模板
- Excel流程识别与SaaS化建议
- ROI计算器（客户愿付价格评估）
- 冷邮件/电话脚本生成器

### Installation
```bash
pip install -r requirements.txt
python src/main.py --help
```

### Tech Stack
Python, requests, pandas, googlemaps
