[English](#english) | [中文](#chinese)

## <a id="english"></a>English

### Overview
A framework for identifying and validating boring B2B SaaS opportunities by analyzing business pain points and Excel-based workflows

### Features
- Business pain point discovery tool
- Excel workflow analyzer
- ROI calculator for B2B solutions
- Local business lead generator (Google Maps scraper)
- Simple MVP builder with minimal UI
- Direct outreach email templates
- Pricing calculator ($100-500/month range)

### Installation
```bash
pip install -r requirements.txt
python src/main.py --help
```

### Tech Stack
Python/Flask（后端）, HTML表格（无需React）, SQLite/PostgreSQL, Google Maps API, SMTP邮件发送
